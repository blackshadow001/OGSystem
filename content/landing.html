Safety Guarantee: Clear Queue vs. Clear Cache

OfficeGuard strictly protects employee files against accidental deletion. The Clear button in the Send Files interface only removes files from the current transfer queue. The employee application's Clear Cache option cleans only temporary transmission buffer chunks and stale staging files—it never deletes original employee documents, completed received files, or office server paths.

QUESTIONS, ANSWERED

Clarity before
you deploy.

Key answers regarding endpoint enforcement, daily employee usability, and operating system integration.

Does OfficeGuard block normal website browsing?+

No. By default, employees can browse websites normally in managed browsers. OfficeGuard evaluates file uploads and unauthorized sharing destinations while leaving general research and portal access open.

Can employees continue using existing office NAS and file servers?+

Yes. OfficeGuard specifically supports existing office server and NAS workflows. Approved internal network shares (such as \\Office-NAS\Projects) are whitelisted so they are never blocked by external storage or DLP policies.

Why are the Clear and Local Transfer buttons two square cards?+

Specification Section 9.2 mandates a clear two-column layout of equal square cards. The CLEAR button removes files from the current send queue (with a guarantee never to delete original laptop documents), while the LOCAL TRANSFER button initiates the 10-step receiver approval handshake.

What happens if an employee laptop disconnects or goes offline?+

The background Windows agent continues enforcing locally cached security policies within their validity window. USB, browser, and application restrictions remain active. When connection returns, buffered audit events synchronize to the central server automatically.

What is the difference between "Clear" and "Clear Cache"?+

The "Clear" button on the Send page removes items from the active transfer queue. The "Clear Cache" option in application settings removes temporary transfer staging chunks. Neither action ever deletes original employee files, completed downloads, or office server data.

How are USB restrictions enforced?+

OfficeGuard enforces USB rules at the Windows operating-system and driver level. This allows policies such as complete mass storage blocking, approved device serial whitelisting, or read-only mode that cannot be bypassed simply by using command-line tools.

Does OfficeGuard collect or store employee email passwords?+

Never. OfficeGuard maintains zero-password knowledge. Identity is established through corporate email account association, device hardware tokens, and supported single sign-on / identity provider integrations.

Why does Local Transfer avoid forced ZIP compression?+

In accordance with Section 9.6, files retain their original filenames, extensions, and directory structures. This eliminates extraction delays and preserves file metadata for engineering, design, and financial spreadsheets.
